# 纸上生花测试与适配说明

项目已完成实际测试，覆盖几何模型、数据库持久化、访客权限、页面交互、响应式布局和动画控制。浏览器布局测试采用桌面Chrome／Edge的模拟视口，故障恢复采用接口延迟与错误注入。

## 1. 测试环境与适配范围

|项目|测试范围|
|---|---|
|浏览器|Chrome 156系列、Microsoft Edge|
|运行环境|Node.js 24系列、PostgreSQL 17|
|页面宽度|360、390、720、768、1440、1920px模拟视口|
|小屏补充检查|320px布局、390×460px可视区|
|交互方式|鼠标、键盘、模拟触屏|
|网络与接口场景|正常响应、900–1600ms延迟注入、503错误注入及重试|
|动态偏好|正常动画、减少动态效果|

在上述已验证范围内，网站具有良好的响应式适配性，能够根据窗口宽度调整为单列或多列布局，主要内容和创作操作保持可用。

## 4. 测试数据与方法

测试作品采用项目参数化模型和独立访客会话。测试脚本创建临时作品、练习记录及收藏，用于验证完整流程，完成后清理自身样本。

慢响应和故障由Playwright路由拦截模拟；标签页隐藏通过document.hidden与visibilitychange信号模拟。窗口宽度、接口延迟和错误码是测试条件，不能代替实体设备、真实网络或其他浏览器版本的测试结论。

## 5. 功能边界

作品支持三类参数化切口、一种对称模式及最多80个切口。草稿恢复依赖访客Cookie，不提供跨设备账户同步。作品保存以服务端成功响应为准，SVG与PNG导出只包含作品本身。数据库独立重启、实体手机与完整读屏检查仍作为后续验证项目。
