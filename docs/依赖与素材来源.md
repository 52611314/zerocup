# 纸上生花依赖与素材来源

直接依赖版本与许可证依据package.json及package-lock.json整理。传递依赖的精确版本以锁文件为准。

## 直接依赖

|依赖|版本|许可证|用途与位置|
|---|---|---|---|
|Nuxt|4.4.2|MIT|页面SSR、文件路由、开发与构建；nuxt.config.ts、app、server，Nitro随Nuxt提供服务端运行|
|Vue|3.5.30|MIT|声明式组件、响应式与交互；app。Nuxt内部还可能解析嵌套版本，实际构建日志曾为3.5.45，不能把根声明误写成所有运行模块的统一版本|
|Vue Router|4.6.4|MIT|页面导航、查询参数与返回；Nuxt集成可能有嵌套依赖版本|
|pg|8.23.1|MIT|服务端连接池、参数化SQL、种子和迁移；server/utils/db.ts及scripts|
|TypeScript|5.9.3|Apache-2.0|类型检查及开发约束|
|vue-tsc|3.2.5|MIT|Vue单文件组件类型检查|
|tsx|4.21.0|MIT|执行TypeScript种子和测试|
|@types/node|24.10.1|MIT|Node开发类型声明|
|@types/pg|8.15.6|MIT|PostgreSQL驱动类型声明|
|@playwright/test|1.58.2|Apache-2.0|浏览器自动化、模拟视口与故障注入，不是用户页面组件库|
|embedded-postgres|17.6.0-beta.15|MIT|可选本机真实PostgreSQL启动器，仅开发／演示；其数据库二进制依赖另保留自身许可|

PostgreSQL采用17系列，Compose固定镜像postgres:17.6，本机启动器提供相应数据库进程。数据库不是由浏览器模拟或localStorage替代。Node、Docker与数据库本体也各有自己的分发许可；源码包不附带这些运行时二进制。

项目没有引入预设样式库、成品页面模板、绘图编辑器、动画引擎或ORM。形状放置、八扇区生成、撤销重做、展开与场景动效由本项目代码实现。

## 图形与字体

|素材|来源及实现|说明|
|---|---|---|
|窗花示例、基础纹样|shared/patterns.ts、shared/model.ts|项目原创参数化数字练习，名称不代表已考证的传统纹样寓意|
|双燕与留白|shared/swallow.ts及对应组件|项目原创SVG轮廓，不是传统实物照片|
|一纸三景|app/components/PaperScenes.vue|项目原创分层SVG，窗月、山影、桥灯及循环均由代码绘制|
|回纹推窗|public/art/lattice-window.svg|参照用户提供的木窗照片重绘，原照片没有打包分发；参考照片作者与授权信息未提供，不宣称已完成其权属核验|
|纸纹、木框、光影、装裱|app/assets/css及PaperRoomLight等组件|项目CSS渐变、线条与SVG，不依赖外链材质图片|
|站标|public/favicon.svg|项目原创图形|
|中文字体|系统宋体类与中文无衬线回退|不随包分发字体文件，实际外观受操作系统字体影响|

展览种子包含6件标为“原创示例”的作品，不冒充访客投稿、馆藏或传统实物。文化札记中的数字练习不作历史传承、人物身份或官方认证的证据。
