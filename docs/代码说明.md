# 纸上生花代码说明

## 架构与职责

项目使用Nuxt、Vue 3和TypeScript，Nuxt服务端渲染公开页面，Nitro处理接口，node-postgres连接PostgreSQL。界面采用原创CSS与SVG，不使用预设样式组件库、ORM或现成页面模板。具体版本和用途见[依赖与素材来源](依赖与素材来源.md)。

|目录或文件|职责|
|---|---|
|`app/pages/`|页面、列表查询、详情和后台入口|
|`app/components/StudioEditor.vue`|切口编辑、历史、展开、导出、保存与教程动作|
|`app/components/PaperArt.vue`|由模型渲染扇区和完整纸样|
|`app/components/PaperScenes.vue`|三景SVG、切景与环境循环|
|`app/components/PaperRoomLight.vue`|栏目顶部共享光影|
|`app/composables/`|写请求、返回路径、章节转场和持续动画生命周期|
|`shared/model.ts`|作品类型、校验、几何、快照历史及SVG序列化|
|`shared/patterns.ts`、`shared/swallow.ts`|原创起始纹样和双燕轮廓|
|`server/services/`|公开读取、私人作品、练习、保存事务和后台服务|
|`server/utils/`|连接池、访客与管理员会话、CSRF、字段校验|
|`db/migrations/`|有校验和的版本化SQL迁移|
|`scripts/`、`tests/`|种子、启动、打包及不同层次验证|

## 作品模型与几何

```ts
type CutType = 'circle' | 'triangle' | 'drop'
interface Cut {
  id: string
  type: CutType
  x: number
  y: number
  size: number
  aspect: number
  angle: number
}
interface PaperModel {
  schemaVersion: 1
  color: string
  symmetry: 'dihedral-4'
  cuts: Cut[]
}
```

基础纸角是半径100、角度0–45°的扇区，最多80个切口。服务端与导出均校验模型：切口ID唯一，数值有限，位置位于基础扇区，尺寸1–28，长宽比0.25–2.5，角度−180–180°，纸色来自四种允许值。圆形单元可按长宽比形成椭圆。编辑时的位置约束还保留内外边距。

第i个扇区的变换规则为：偶数i旋转i×45°；奇数i先镜像y，再旋转(i+1)×45°，i从0到7。切口先按自身位置和角度变换，再经基础扇区裁剪，最后通过八组变换形成整图。SVG mask把切口作为黑色去除区域，保留彩色纸面，交叠切口形成统一留白。

`ModelHistory`保存深拷贝快照；提交模型会清空redo栈，最多保留100个past快照，相同模型不重复记录。该历史用于当前编辑会话，数据库保存当前作品模型，不宣称刷新后恢复全部撤销栈。

`svgMarkup()`校验模型并生成1200×1200 SVG；PNG由浏览器将同一SVG绘制到Canvas后编码。网页预览和导出复用切口路径及对称变换，装裱、背景纹理和环境动效不写入作品文件。

## 保存与学习事务

首次保存新建作品，后续PATCH携带version。更新SQL同时约束作品ID、owner_id、version及可编辑状态draft／rejected；不匹配返回409，避免静默覆盖另一个标签页的更新。前端保留当前编辑，并允许重试或另存。

有关联练习时，保存事务先锁定当前访客的活动练习，随后保存作品，并在同一事务中设置work_id。过期或别人的练习不能绑定。创建／重开练习时锁定访客行，使用部分唯一索引保证同一访客、课程只有一个active记录。

练习进度和历史最高进度分开：tutorial_runs表示本次步骤，tutorial_progress通过GREATEST保留历史最高值。带runId的步骤更新只允许同一步幂等提交或前进一步。服务器验证归属、顺序和范围；没有在服务器重新模拟浏览器里的每次剪切动作。

## 数据库

|表|用途|
|---|---|
|visitor_sessions|访客令牌摘要与有效期|
|admins、admin_sessions|管理员密码摘要和登录会话|
|articles、patterns、tutorials|文化正文、来源、纹样模型和教程步骤|
|works|模型JSONB、归属、状态、版本、分类与展示排序|
|tutorial_progress、tutorial_runs|最高进度和当前练习及作品关联|
|favorites|访客与公开作品的收藏关系|
|rate_limits、admin_audit|限流计数与后台操作记录|
|schema_migrations|迁移文件名、校验和及执行时间，由迁移脚本创建|

作品格式没有拆成每个切口一行，完整模型保存在JSONB中。公开作品索引、访客作品索引和练习活动唯一索引用于对应访问路径。数据库连接池最大10个连接；查询数据值使用参数绑定。后台表名来自articles／patterns／tutorials白名单，不接受用户任意表名。

|迁移|含义|
|---|---|
|001_initial.sql|内容、作品、访客、管理员、进度、收藏与审计等基础结构|
|002_tutorial_runs.sql|新增独立练习记录与活动唯一索引|
|003_demo_auto_approval.sql|展示策略下公开已有pending作品；不公开未投稿draft|
|004_demo_tutorial_note.sql|精确匹配并更新默认教程的投稿说明，保留自定义文案|

迁移脚本持有数据库advisory lock，逐文件事务执行并校验SHA-256，已执行迁移不得原地改写。种子创建8个纹样、6篇札记、3个教程和6件明确标识的示例，重复运行保留现有内容，但会按配置重设管理员密码。

## 主要接口

下表路径均以`/api`为前缀，字段与完整校验以服务端实现为准。

|方法与路径|主要行为|
|---|---|
|GET `/health`|真实数据库连接检查|
|GET `/articles`、`/articles/:slug`|公开札记列表与正文，列表支持q与category|
|GET `/patterns`|公开起始纹样|
|GET `/tutorials`、`/tutorials/:slug`|公开课程列表与步骤|
|GET `/gallery`、`/gallery/:id`|只读published作品；列表按q、category、page过滤，每页6件|

|GET `/me/works`、`/me/works/:id`|当前访客作品及恢复模型|
|POST `/works`、PATCH `/works/:id`|新增或更新本人可编辑作品|
|POST `/works/:id/submit`|校验归属后直接发布，增加版本|
|GET／POST `/me/practice/:tutorialId`|读取、开始或重开当前练习|
|GET `/me/progress`、PUT `/me/progress/:tutorialId`|学习进度读取与受约束更新|

|PATCH `/admin/works/:id`|版本校验后调整排序、公开或撤展退回|

## 权限与发布

访客凭随机HttpOnly Cookie恢复本人作品，数据库只保存令牌SHA-256摘要，会话有效期90天。管理员密码使用带盐scrypt摘要，管理员会话8小时；不把账号密码写入提交源码。

`writeApi()`先取CSRF令牌，再携带x-paper-csrf写入。令牌与当前访客Cookie绑定，服务端恒定时间比较，并核对会话是否有效。来源检查通常精确匹配配置origin；本机开发和本机生产预览的来源头异常有受约束的会话令牌补偿，公网跨站请求不因此放开。接口请求体限制64KB，并对登录、作品写入等实施限流。

状态字段保留draft、pending、published、rejected。当前展示路径是draft／rejected投稿后直接published；pending为历史兼容状态，不是当前访客必须等待的管理员步骤。管理员可退回已发布作品；公开接口与站点地图只查询published，不以隐藏按钮代替权限检查。匿名链接持有人不能仅凭作品ID读取别人的私人草稿。

## SSR 导航与动效

公开文化详情、课程和作品具有独立URL、标题、摘要与canonical。robots和routeRules限制工坊、纸笺、后台索引；站点地图从公开内容及published作品生成。搜索与分类由路由参数驱动，详情返回入口存在当前Nuxt状态中，不代表跨浏览器历史同步。

`useAmbientMotion()`结合IntersectionObserver、visibilitychange与prefers-reduced-motion控制循环；卸载时清理观察器和监听。三景内部小组承担循环，外层承担切景，线条双副本错相并在透明时重置。展览的装裱装饰与实际作品分层，避免让作品延后显示或跟随底座旋转。

## 已知边界

没有用户注册、跨设备同步、任意曲线、图片识别导入、真实剪纸连通性计算。后台正文采用结构化heading／text数组，不提供任意HTML执行。实际测试范围见[测试与适配说明](测试与限制.md)。
