# 纸上生花

参赛文档包括[设计说明](docs/设计说明.md)、[代码说明](docs/代码说明.md)、[部署与演示](docs/部署与演示.md)、[测试与限制](docs/测试与限制.md)、[依赖与素材来源](docs/依赖与素材来源.md)。完整版另附队伍信息。

2026 年零杯网页设计大赛主题二“匠心传承，非遗焕新”。从纸上学堂认识剪纸，在基础扇区里创作，再展开、保存和投稿。当前展示版本投稿即时通过并公开，未投稿草稿保持私密。

## 环境与启动

环境采用Node.js 24、Docker Compose和PostgreSQL 17。详细步骤见[部署与演示](docs/部署与演示.md)。

首次配置环境并修改`.env`中的数据库密码、管理员账号密码和SITE_URL：

```powershell
npm ci
Copy-Item .env.example .env
```

启动Docker Desktop后执行：

```powershell
docker compose up -d db
npm run db:migrate
npm run db:seed
npm run build
npm start
```

默认入口为http://127.0.0.1:3000，后台为`/admin`。页面和接口由同一Nuxt应用提供。已有数据库升级时运行迁移即可，重复seed会按环境配置重设管理员密码。生产预览修改源码后重新构建、重启；开发调试使用`npm run dev`。

环境变量SITE_URL应与实际访问根地址一致。浏览器通过访客Cookie和CSRF令牌保存私人作品；草稿恢复与当前浏览器会话关联。数据库、环境配置、必要依赖和版本化SQL保留在各自目录。

## 三分钟演示

1. 在首页点“看留白”，观察团花翻色后显出双燕。点“推窗进工坊”，看全屏格窗向里缓开，露出裁切台。回首页向下滚至窗廊，试学堂翻图谱、教程折纸和展览圆形揭幕。进入学堂打开一篇札记，查看来源，再点“用此纹样开始”。
2. 将浏览器切到 390px。添加水滴，用方向按钮移动、调整大小、撤销和重做，再展开。
3. 命名并保存，刷新工作台核对图案。下载透明 PNG，或到“我的纸笺”恢复。
4. 投稿后立即自动通过并公开。点“查看已公开作品”，或在展览搜索作品名称；无需管理员操作。
5. 从展览详情复刻作品。后台修改札记摘要，刷新学堂详情观察更新。
6. 停止并重启应用和数据库，保留 .data 与访客浏览器 Cookie，复核草稿与发布状态。

## 设计与代码

当前展示策略为投稿即时通过。更新后执行 npm run db:migrate，003迁移会自动公开既有待审投稿，004同步默认教程提示。草稿在投稿前保持私密。逐步操作及预期效果见 [部署与演示](docs/部署与演示.md)。

工坊透光扩展暂缓，展开预览使用原有居中纸样。首页展览纸窗与展览封面使用实际公开作品，作品列表为空时显示等待状态。教程记录一步后会把焦点带到下一工具，保存保持原页内锚点。

场景动画：在首页「一纸三景」切换三幅画面，观察单向流动的云线与前景线、移动月光及水边灯光。学堂、教程和展览顶部均有窗影与柔光移动，学堂背景纹样微转，展览装裱外圈与底座光泽流转，作品本体不跟随转动。完全离开视口或隐藏标签页时暂停，减少动态效果时呈现静态画面。

朱砂红表示纸面和主操作，纸白表示被剪去的空隙，墨黑用于阅读。标题采用系统宋体。手机将画面置于工具上方。切口可以点击放置，也可通过按钮添加和调整。减少动态效果时立即显示完整图案。

shared/model.ts 定义有版本的作品格式、基础扇区、镜像与旋转、快照历史及 SVG 序列化。PaperArt.vue 与导出复用相同的切口路径及扇区变换。PNG 由浏览器绘制同一 SVG。没有连通性、任意曲线切割或物理仿真。

server/services下按公开查询、私人作品和后台分工。服务端校验访客Cookie、作品归属、提交来源与版本；数据库通过带状态和版本条件的更新防止覆盖。当前作品由draft／rejected投稿后直接published；pending保留作历史兼容。数据库保存会话令牌摘要与密码哈希。公开详情与站点地图只查询已发布记录。教程区分历史最高进度与本次练习，收藏按访客与作品唯一。

## 依赖与素材

推窗转场的 public/art/lattice-window.svg 依照用户提供的回纹木窗照片重绘，网页使用矢量格栅和双扇动画，不附带原照片。

固定版本及传递依赖见 package-lock.json。Nuxt 4.4.2 提供 SSR、路由和 Nitro，Vue 3 与 Vue Router 提供交互与导航，pg 8.23.1 在服务端与迁移脚本使用参数查询。TypeScript、vue-tsc 和两个 @types 包用于类型检查，tsx 执行种子与测试，Playwright 用于浏览器验证，embedded-postgres 17.6.0-beta.15 仅启动真实本地 PostgreSQL。项目未使用预设样式库。所有剪纸几何、展览示例、CSS 纹理和站标均为项目原创。系统字体随设备提供，无字体文件分发。文化来源逐篇列在知识详情与 /about。

技术参考见 [Nuxt 4 服务端](https://nuxt.com/docs/4.x/directory-structure/server)、[Vue 组合式 API](https://vuejs.org/guide/typescript/composition-api)、[pg 参数查询](https://node-postgres.com/features/queries) 与 [PostgreSQL 17](https://www.postgresql.org/docs/17/)。
